# Focus

Personal Android app (sideloaded): focus lock, allowed callers, earned Time Bank. Target: Galaxy A32 (Android 13).

- Build: GitHub Actions builds a debug APK on every push to `main` and attaches it to a Release (`build-N`).
- Specs and design handoff: `docs/`.
- No secrets in this repo. Strava and Notion keys are entered inside the app.
